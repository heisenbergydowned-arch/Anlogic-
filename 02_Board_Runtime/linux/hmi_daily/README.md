- 默认一个日常数据屏：转速、设备温度、电流、风道压差，转速/温度趋势，A/B 六轴 RMS、16 个频带功率占比和 A/B 比值。

- 健康基线流程：准入→等待稳态→采集→时间分块留出验证→候选确认→原子保存；可取消、超时中止、重新学习和兼容版本回退。
- 单设备当前 RPM 工况的中位数/MAD/噪声底及冻结偏离检测；不修改旧 NPU 的输入、scaler 或权重。
- 配置/会话/质量/新鲜度门控、短保护事件中止、持久请求去重、SQLite FULL/WAL、候选掉电不启用、校验和及统计结构检查。
- 原采集器同时供显示和学习使用；本地 Unix socket 为 0600，目录为 0700。学习模块没有 MMIO/执行器接口。

本版只有一个 ACTIVE 工况基线；重学并确认后旧版本进入历史，可回退。不支持同时多 RPM 基线、自动扫速、连续增量学习、在线 NPU 训练、故障原因分类或自动调整硬保护阈值。

## FPGA 与数据边界

现有 PL 已输出全部 39 维、帧质量、时间/版本、控制/保护状态，足以支持本版，不需要新增 FFT/学习 RTL。本次未修改 RTL、位流、BOOT.bin、SD 启动文件或保护参数。

板端 FPGA 工程配套源码入口已同步到工作区 `fpga_work/working/src/edge/linux/hmi_daily/`；它是 Linux 配套应用，不是新 TD 位流。数据继续来自 0x80400000 的 FCB1/EDG1/FRM1，唯一消费者只进行已有 cookie 登记、状态 snapshot 和精确帧 ACK。

显示资格与健康学习资格不同：未知/失效值显示 `--`，没有有效数据不画假曲线。电流/压差在标定合同匹配前保留原始码；频带是归一化功率占比，不是绝对能量。旧帧、版本失配、失效当前传感器不能变成有效工程量。

NPU 未接入本显示服务，不展示假分类。学习“与本工况一致”不是系统健康证明，不能撤销过流、停转、过热、保护丢失或已有锁存。

# 2026-10-23 ADC 未标定显示修复

仅连接 AD7606 时，CH1 模拟输入悬空仍可能产生跳动码值，不代表已连接电流传感器，更不能当作零安培。工业页面未标定时显示 `ADC CH1 原始码`，取 FCB1 状态字22低16位的有符号输入码；不要把状态字21的零点距离幅值冒充有符号采样值。缺少该状态字的兼容数据明确标为幅值。失效数据仍隐藏，不等待完整39维特征帧才显示有效ADC诊断值。

仅当真实特征帧新鲜、质量合格、标定和当前合同匹配时才显示安培。其他未接的DS18B20、FG、SDP810、IMU等独立传感器保持 `--`，不会用ADC悬空读数代替。电流/ADC卡片统一使用Montserrat 28字体（LVGL行高30），不随位数自动放大缩小，超出显示宽度时显示无效提示。自适应学习和保护门禁不变。
