# SDP810-500Pa 数字压差接入

日期：2026-10-13。只更换压差采集，保留 AD7606、ACS712、电流 50kS/s、双 ICM、DS18B20、FG/PWM、39 维顺序和单位。IC Coder 在隔离候选目录编写驱动和三客户端仲裁器，Codex 审核、接入并补充窗口、保护、总线级和读取契约测试。

## 硬件和工程入口

- 压差器件为 **SDP810-500Pa**，不是 SDP816 模拟版，也不是 125Pa 或 SDP3x 型号。地址 `0x25`，供电和 I2C 上拉按 3.3V 接口核对。J12 Pin18 SDA、Pin20 SCL，与 AHT20/BMP280 共用；气管分别接滤网上、下游静压取压口。
- AD7606 CH1 保留电流，CH2 不再作为数字方案的压差来源。ADC 仍读取原有 8 通道帧，未修改 `ads7606_if.v` 或其 50kS/s 配置；空闲模拟通道不得悬空后被当成传感器数据。
- `subsys_acq.ENABLE_SDP810=1` 是默认活动方案，REAL 特征使用数字压差；`ENABLE_SDP810=0` 保留旧模拟压差兼容入口。TEST 特征继续使用有 TEST 标记的原模拟测试源，不证明真实传感器。
- `soc_prj.al`、`cooling_link.al`、`cooling_link_test.al` 注册了两个新模块。没有修改 HDMI、NPU、`design_0`、引脚约束或时钟约束；已有工程报告不再代表修改后的资源与时序。

## 驱动与故障语义

1. 上电等待 20ms；向 `0x25` 发停止命令 `0x3FF9`，等待至少 1ms，不发共享总线 general-call reset。
2. `0x367C`、`0xE102`、等待 1ms，再读 18 字节。全部 6 个字校验 CRC；产品号高 24 位必须是 `0x03020A`，低 8 位允许版本差异。
3. `0x361E` 开始连续差压温补、不使用传感器平均模式，等待 20ms。之后纯读 9 字节，正常请求间隔目标 10ms，完成时间包含总线事务和轮询等待，不能宣称严格 100S/s。
4. 校验压力、温度、比例因子三个 CRC，比例因子必须是 60，原始压力在 `[-30000,30000]`。负数绝对值用 17 位计算；截断、重复、乱序、额外字节都拒绝。最后字节与 ACK 同拍仍要正确验证。
5. 完整有效读数才产生一拍 `sample_valid`。故障保留旧数值供排查，但不重新发布；没有有效样本或超过 100ms 时 `stale=1`。CRC/命令成功不能刷新最后有效样本的年龄。
6. 请求超时上限 100ms；任何测量故障经 100ms 重试延迟重新执行停止、身份检查与启动，不会每次正常轮询都重启。三客户端事务轮询公平仲裁、锁定所有者；单事务看门狗 20ms，超时或撤销会复位/排空 I2C 主机再移交。

错误码：`00` 无测量错误；`01` 总线/NACK；`02` 请求无 ACK 超时；`03` 帧顺序/长度；`04` CRC；`05` 产品型号；`06` 比例因子；`07` 超量程。启动时 `err=1,stale=1`，错误码 00 不单独代表健康。`present` 表示产品身份曾验证，必须同时检查 `err`、`stale`，不能只看在线位。

## 独立窗口和保护

- 电流和压差分别累计有效新样本、和及计数，仍以两片 ICM 的 1024 点/512 hop 窗口组织。不会把 10ms 压差的旧值重复按 50kHz 累加。
- 当前 `0x361E` 读取的是传感器瞬时结果，窗口均值不等于读取前抗混叠滤波。台架需检查转频/叶频压力脉动与读节拍的相关偏差；如影响堵塞判据，再评估原厂 `0x3615` 区间平均模式或提高读取率。切换平均方式须同时改总线模型、命令断言、构建标识与采样契约，并重新采健康基线，不能只改一个命令字后继续沿用旧阈值。
- 质量位 8 是电流无效，位 10 是压差无效；数字方案二者独立。CRC 错误、断线、过时、窗口无有效压差样本均使压差无效；真实 0Pa 只有完整有效读数才有效。
- 压差故障进入原诊断数据丢失路径；不阻塞 ADC、FG、PWM、温度保护和特征采集。快速过流输入仍是 AD7606 CH1，与 I2C 事务无关。仿真保护动作不是实际断电证明。

## 39 维和 Linux 契约

保留 FRM1 的 32 个头字、39 个 FP32、总长 284 字节，`pressure` 仍是索引 37 的 **kPa**。数字原始码为 60 counts/Pa；默认压力零点 Q16 为 0，增益 Q30 为 `17896`，约等于 `2^30/60000`。这是名义系数，不是实机标定。电流系数不变。

必须按 `header[18]` 的采样模式解释数据，不能只凭帧版本相同套用旧标定：

| 字段 | 模式 1：旧模拟/TEST | 模式 2：数字压差 REAL |
|---|---|---|
| `header[13]` | ADC/模拟压差共用的 32 位有效计数 | 低 16 位 ADC 有效计数，高 16 位压差有效计数 |
| `header[18]` | 1 | 2 |
| `header[22]` | ADC 配置 50000S/s | 同样 50000S/s，仅指 ADC，不是压差速率 |
| `header[30]` | 模拟 ADC 压差窗口均值码，Q16.16 | SDP 原始 counts 的窗口均值，Q16.16 |
| `header[26]` | 活动顶层新构建标识 `202610b0`，与 TEST 位分别核对 | 活动顶层新构建标识 `202610b0` |

模式 2 计数超出 16 位时整帧置数值溢出质量位，禁止无声截断后取得诊断资格。`cabinet/protocol.py` 与 Python3.6 HMI 对应读取器均已增加独立计数解码；旧读取契约默认模式 1，会拒绝模式 2，不能通过忽略检查让它接受新数据。

FCB1 状态位中的 `pressure_valid` 已改成独立压力新鲜度。状态 word22 高 16 位在数字方案中是 SDP 原始 counts，不是 MPXV7002/AD7606 码；低 16 位仍是电流 ADC 码。不要把原始状态码直接显示成 Pa 或 kPa。

名义配置模板：`src/edge/linux/feature_config.sdp810.example.json`，保持 `qualified=false,calibration_id=0`。Linux/算法负责人确认新 `sample_mode_id=2`、实际标定与新配置/标定 ID 后再取诊断资格。旧健康基线、旧压力阈值、合成数据上的模型成绩不得直接沿用；模型仍输入 39 维，不自动增维或在线改权重。
