## 1. 已实现的计算

| 类别 | 数量 | 实现 |
|---|---:|---|
| 振动时域 | 18 | A/B 六轴分别去均值，未加窗的 RMS、峰峰值、Pearson 峭度（不减 3） |
| 振动频域 | 16 | 共进行 **6 次 1024 点 FFT**，复用一个核；每点三轴的单边功率合并，再按 8 个频带累加、除以该点总能量 |
| 双点比值 | 1 | 已输出的 A x/y RMS 之和除以 B x/y RMS 之和，限制到 0.3–6 |
| 过程量 | 4 | 主模块接收同一窗口的 A、℃、kPa、RPM 快照；另提供原始窗口均值到工程量的转换模块 |

振动比例假定 ICM-20602 为 **±8g、4096 LSB/g**。量程改变时必须同步修改 RMS/峰峰值换算和参考程序。
RMS 使用去直流后的振动分量，排除重力和固定偏置；若算法组选择包含直流的 RMS，应同步修改软件参考和 RTL，重新训练。

计算定义：

```text
N = 1024
d[n] = raw[n] - mean(raw)
rms = sqrt(sum(d²)/N)/4096                 单位 g
pp = (max(raw)-min(raw))/4096              单位 g
kurt = N*sum(d⁴)/(sum(d²))²               Pearson 峭度，正态信号约 3
Hann[n] = 0.5*(1-cos(2*pi*n/N))            周期 Hann
X = FFT(d*Hann)/N
P[k] = 2*|X[k]|², k=1..511; P[512]=|X[512]|²
Epoint[band] = sum(Px+Py+Pz, bins in band)
bandpoint[band] = Epoint[band]/sum(Epoint[0..7])
```

DC bin 0 不参与频带。Nyquist bin 512 参与且不翻倍。Hann 窗仅用于频域。
时域均值保留 10 位小数，FFT 输入保留 12 位原始码小数；蝶形乘法和缩放使用最近偶数舍入。输出 Q16.16 在除法处向下取整。
全零方差时 RMS/pp/kurt 和频带置零；A/B 均为零时比值为 1，只有 B 为零时比值为 6，并置质量标志。归一化之和可能因 Q16.16 截断比 1 小最多 8 LSB。

## 2. 固定输出顺序

| 索引 | 特征 |
|---|---|
| 0–2 | rms_a_x、rms_a_y、rms_a_z |
| 3–5 | pp_a_x、pp_a_y、pp_a_z |
| 6–8 | kurt_a_x、kurt_a_y、kurt_a_z |
| 9–16 | banda0–7 |
| 17–19 | rms_b_x、rms_b_y、rms_b_z |
| 20–22 | pp_b_x、pp_b_y、pp_b_z |
| 23–25 | kurt_b_x、kurt_b_y、kurt_b_z |
| 26–33 | bandb0–7 |
| 34 | ratio_ab |
| 35–38 | current（A）、temp（℃）、pressure（kPa）、rpm（RPM） |

39 项与 `gen_sensor_dataset.py` 的名称和顺序一致；**名称一致不代表原合成模型已通过真实信号验收**。
`out_q16` 是有符号 32 位 Q16.16，`out_fp32` 为同一量的 IEEE754 binary32 位模式，无需再次做 StandardScaler（现有纯 FP32 NPU 模型已合并 scaler）。
FP32 转换采用最近偶数舍入；所有工程量需在 Q16.16 范围内，即约 −32768 到 +32768。

## 3. 频带配置

默认 bin 边界为 `[1,13,39,65,103,154,205,257,513]`，每段为左闭右开。

| 频带 | bin 范围 | Fs=4000Hz 时包含的频点中心范围 |
|---|---|---|
| 0 | [1,13) | 3.90625–46.875 Hz |
| 1 | [13,39) | 50.78125–148.4375 Hz |
| 2 | [39,65) | 152.34375–250 Hz |
| 3 | [65,103) | 253.90625–398.4375 Hz |
| 4 | [103,154) | 402.34375–597.65625 Hz |
| 5 | [154,205) | 601.5625–796.875 Hz |
| 6 | [205,257) | 800.78125–1000 Hz |
| 7 | [257,513) | 1003.90625–2000 Hz |

实际频率满足 `f[k]=k*Fs/1024`。本模块不能改变或检测真实采样率。
默认频带是固定区间，不会自动随 RPM 移动；6000RPM 的 100Hz 基频落在 band1，转速变化后不能一直把 band1 称为“1×转频”。算法组若采用跟随转速的频带，应按窗口更新边界，并在训练和推理中使用同一规则。
**当前 FFT 目标为每轴 4kSps，尚未获得真机有效率验收。** 活动顶层使用 8kHz 轮询；ICM 初始化已修为 `PWR_MGMT_2(0x6C)=0x07`、`I2C_IF(0x70)=0x40`，并有配置回读及模型语义检查。旧版 `0x38` 会禁用三轴加速度计的错误已经修复，不再列为当前源码待办。不能以初始化注释或仿真模型的 ODR 证明真机 4k 已实现；Fs 改变时须同步默认 bin 的 Hz 解释、参考程序及训练配置。
4kSps 时 Δf=3.90625Hz，1024 点窗口 256ms；50% 重叠由上游实现，步长 512 点/128ms。
ICM 的约 1046Hz 带宽也不能因 FFT 的 Nyquist 达 2000Hz 就变成 2000Hz 的有效传感器带宽。

仅 `frame_ready=1` 时写配置。`cfg_we=1`、`cfg_index=0..8`、`cfg_edge=边界bin`。
边界要求严格递增、首项 1、末项 513，因此完整覆盖正频点。一次帧开始时验证并锁存；非法配置沿用最近有效配置，并置质量 bit1。未接收过有效配置则使用复位默认配置。
配置写和帧开始必须分开时钟，`cfg_we` 与 `frame_start` 同时出现时仅写配置。

## 4. 采集组接入合同

1. 建立共同时间窗口、给出 `frame_id`。A/B 的独立样本序号相等不证明时间对齐；应按采集时间戳组织窗口。
2. 准备每轴 1024 个**新样本**，不重复使用轮询读到的旧数据。每帧六轴原始样本共 12KiB。
3. 当 `frame_ready=1` 且 `cfg_we=0`，拉高 `frame_start` 一个时钟，同时给出 frame_id、4 个过程量和 input_quality。模块在此时锁存快照。
4. 按 **Ax[0..1023]、Ay、Az、Bx、By、Bz** 的轴优先顺序发送，共 6144 个 signed int16。仅 `sample_valid && sample_ready` 时消耗一个样本。可以有输入间隙。
5. `sample_ready` 在处理本轴期间会拉低，因此必须从缓存发送；不能把 ICM 的一次性 valid 脉冲直接接到这里。
6. 50% 重叠、双缓存、丢样检测、温度新鲜度和 FG 超时属于窗口组织接口；用 `input_quality` 上报。模块允许输入/输出暂停，但暂停过长会阻塞下一帧。
7. 全部接口与 `clk` 同域；跨时钟数据用 FIFO/握手整组传递，不要逐位同步原始总线。

过程量由**同一时间窗口**提供：AD7606 CH1/CH2 保留 50k 采样，标称 256ms 窗口每通道约 12800 点，以实际有效计数求均值，不直接抽点降到 4k；温度采用窗口截止时最近的有效 DS18B20 转换结果并检查年龄；FG 对窗口内周期求均值后换算转速。ADC 均值累加和定点换算必须防止溢出，并保留缺帧质量标志。
FG 转速的定义是“平均周期的倒数”，不是每脉冲转速的算术平均。温度暂定取设备旁 DS18B20-B，采集与算法组确认训练列的物理含义后冻结。A/B 实际 ODR 有偏差时，先冻结时间窗配对或共同网格重采样规则；本模块不负责自动补样、重采样或时间对齐。

## 5. 过程量转换辅助模块

`feature_process_convert.v` 接收已组织好的窗口均值，**不负责原始 ADC 数据的累加和窗口切分**。
ADC 均值是有符号 Q16.16 原始码，保留不足一个码的均值；温度输入是 DS18B20 有符号 1/16℃；FG 周期是采集时钟周期数。
`start && !busy` 锁存一次快照；`done` 脉冲后四个输出和质量保持到下一次转换。转换完成后再给特征模块 `frame_start`。

默认系数仅为数据手册标称：AD7606 ±5V、ACS712-05B 185mV/A、MPXV7002DP 在 5V 供电时 1V/kPa，二者零点均 2.5V（code=16384）。
线性换算使用参数 `CURRENT/PRESSURE_ZERO_Q16` 与 `CURRENT/PRESSURE_SLOPE_Q30`。实测零点和增益后替换，未标定时不能作为测量精度验收。
`CLK_HZ` 默认 100MHz、`FG_PULSES_PER_REV` 默认 2，两项必须与真实 FG 采集时钟和风扇每转脉冲数一致。
转速或线性换算超出 Q16.16 时饱和并置 bit3；FG 无效/周期为零则 rpm=0、bit11=1。

手册来源：[Allegro ACS712](https://www.allegromicro.com/-/media/files/datasheets/acs712-datasheet.pdf)、[NXP MPXV7002](https://www.nxp.com/docs/en/data-sheet/MPXV7002.pdf)。

## 6. 输出与质量标志

当 `out_valid && out_ready` 时消费一个特征。每帧固定 39 次握手，索引从 0 到 38，最后一项 `out_last=1`。
暂停时 valid、索引、Q16、FP32、frame_id、quality 均保持稳定。最后一项被接收后 `frame_done` 脉冲一个时钟，重新允许下一帧。

| 位 | 含义 |
|---|---|
| bit0 | 零方差、零频谱能量或比值分母为零 |
| bit1 | 非法频带边界，沿用最近有效边界 |
| bit2 | 输入包含 int16 极值，存在饱和可能 |
| bit3 | 过程量换算超出 Q16.16，被限幅 |
| bit4–7 | 上游可用，例如丢样、窗口对齐失败；提取模块只透传 |
| bit8 | current 无效 |
| bit9 | temp 无效/过期 |
| bit10 | pressure 无效 |
| bit11 | FG/RPM 无效/超时 |
| bit12–15 | 上游保留 |

`input_quality` 与本模块检测的标志做 OR。读取方应检查整帧 quality 后决定是否推理；不能把缺失过程量的补零当成有效测量。

## 7. 构建、验证与分工

生产 RTL 清单见 `feature_sources.f`。TD 加入这些 `.v` 文件，并在消费端接入后实例化 `feature_extract`；不要把 `sim/tb_*.v` 加入综合。
当前 `feature_extract` 尚未实例化到活动 `system_top.v`；本轮没有修改 RTL 或活动 `.al`，独立模块不会自动参与整机位流。接入前先评估当前合并工程资源与残余时序，接入后重新完整综合布线。

运行回归：

```powershell
powershell -ExecutionPolicy Bypass -File .\run_regression.ps1
# 可传入 -Python、-Iverilog、-OutputDirectory
```

依赖 Python+NumPy、Icarus Verilog。测试包括 40 个大整数算术向量、6 次独立 FFT（6144 个复数频点）、6 个过程快照、12 帧全链路（468 个特征），以及输入间隙、输出背压、复位中止、有效/非法频带配置。
全链路参考是 NumPy 浮点计算，不复制 RTL 蝶形算法。结果写入 `sim/results/regression_report.json` 和 CSV，日志与输入向量一并保留。

实测原始 CSV 可用 `tools/feature_reference.py frame.csv --process 1.2 35 0.1 6000 --fs 4000 --output features.json`。CSV 无表头、1024 行、列顺序 Ax/Ay/Az/Bx/By/Bz；也支持 (6,1024) 或 (1024,6) 的 `.npy`。
`--fs` 记录真实采样率并说明 bin 对应频率，不对输入数据重采样。更改频带使用 `--edges`，需与 RTL 配置一致。
