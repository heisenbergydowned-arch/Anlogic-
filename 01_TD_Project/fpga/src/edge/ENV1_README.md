# 单S4b温度拓扑及ENV1接口

日期：2026-10-22。源码候选，不自动更新SD、BOOT或Flash。

## 固定测点与安全边界

- 唯一DS18B20/S4b，紧贴发热器件散热片：J12-16/V10，3.3V三线供电、DQ外部4.7k上拉。仍是FCB1温度状态、过热规则、温度外环、39维temp和健康基线温度的唯一来源。
- J12-19/Y9为普通闲置脚IO_j12_19_reserved，永久高阻且内部弱上拉，不属于温度采集通道。未接该脚不会产生辅助故障；真实AHT20/BMP280故障仍产生AUX_LOSS。
- AHT20位于进风侧，提供进风温度℃/相对湿度%；BMP280提供绝对气压hPa和补偿用芯片温度，不能当成器件温度、AHT湿度后备或SDP810差压。
- 39维末四项仍为零基35 current / 36 temp / 37 pressure / 38 rpm。BMP不是pressure的来源。原特征配置、FIR/频带、标定、模型权重及Scaler不改。
- 调试串口字节布局保持，固件版本为0x20261092。d_inlet_aht_q4明确为AHT进风温度Q12.4，d_core_temp_q4明确为唯一DS18B20/S4b核心温度；状态bit3/10分别为AHT有效/陈旧。解析器必须按版本和实际来源标注，不能再显示双DS18B20。

## 发现与地址

UIO仍映射物理0x80400000，大小64KB；不新增设备树节点。原EDG1读0x1040的bit31表示ENV1能力，bits16:0仍是配置已写掩码；写配置提交的语义不变。旧位流bit31为0，Linux明确显示FIRMWARE_UNAVAILABLE，绝不试读新页面（避免旧PL返回SLVERR/SIGBUS）。FCB1/EDG1 ABI不变。

ENV1为同一采集时钟域的只读原子快照。读0x3000创建新快照并返回magic；顺序读其余19字，再重读0x3008核对快照ID。不能在多进程/维护UART并发读取时争用快照；常驻服务仍是唯一MMIO所有者。错位、越界和写入返回错误。

| 偏移 | 32位内容 |
|---|---|
| 0x3000 | 0x454e5631，读取时锁存 |
| 0x3004 | ABI 0x00010000 |
| 0x3008 | 快照ID |
| 0x300c | PL毫秒时钟 |
| 0x3010 | bit0 AHT有效、1 BMP有效、2 AHT存在、3 AHT错误、4 AHT陈旧、5 BMP存在、6 BMP错误、7 BMP陈旧 |
| 0x3014/18 | AHT/BMP最近有效新样本年龄ms |
| 0x301c/20 | AHT湿度/温度20bit原始码 |
| 0x3024/28 | BMP温度/压力20bit原始码 |
| 0x302c..3040 | BMP 0x88..0x9f原始校准字节，小端连续24字节 |
| 0x3044/48 | AHT/BMP有效新样本累计数 |
| 0x304c | DS物理拓扑掩码2，仅B |

默认新鲜度2500ms；只有驱动通过一轮新测量后才更新样本年龄，不以present或轮询读取代替新样本。过期状态保持至新样本恢复，避免32位时钟一整圈后旧样本复活。AHT校准位/CRC/busy错误、BMP通信错误、P1无效或跳过转换码不授予有效性。

PS使用同一数学实现：`hmi_daily/cabinet/environment.py`；业务包`cabinet/environment.py`只转发。AHT T=code×200/2^20−50，RH=code×100/2^20；BMP按Bosch校准补偿，温度范围−40..85℃、绝对气压300..1100hPa。BMP芯片温度不是空气温度的精确替代。数值无效、帧/服务/读取过期均置None/--，不返回有效零值。Linux公共状态和订阅队列延迟扣除剩余有效期，LVGL再检查单调时钟截止时间。

## 单采集服务和HMI

`Service.io_loop`在现有硬件线程读取ENV1，送只读订阅、state.json/state.txt和采集JSONL环境旁路；模型只收到原39维。没有第二个MMIO读取进程，没有环境传感器自动接管温控。

HMI保留单页工业矩阵和PL/NPU/健康基线三层，核心卡片标S4b；左下两行分别显示进风AHT20/RH、环境BMP280/hPa与芯片温度。日常/实验记录界面都有此显示，无有效数据显示--，预览明确标合成。

学习继续网页双确认、安装/标定/保护/模型资格门禁，不清硬保护、不改权重。新增完整上游FRM1序号/丢窗/邮箱丢弃连续性检查；任务期间变更作废候选，历史累计值本身不永久锁死。事件恢复不再受最近1000条分页截断；FIFO持久化后确认有独立保留槽，普通命令队列满不能丢确认，确认失败按boot/id重试。
